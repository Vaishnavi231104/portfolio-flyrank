AuraFlow AI

LangGraph, FastAPI, SQLAlchemy, Streamlit, Groq (Llama 3.1 8B and 3.3 70B). Deployed on Render and Streamlit Cloud.

The problem

People start the day with a pile of unstructured thoughts: tasks mixed with worries and half-ideas. Sorting that by hand costs the focus it was meant to protect, and unfinished items quietly disappear.

What I did

I built an agent that takes raw morning text and returns structured tasks with a category and a priority. A LangGraph state machine routes each request by trigger. The morning path runs a classifier and then an overdue surfacer that pulls unfinished items from the database. The evening path runs an end-of-day summarizer and a next-day planner. FastAPI exposes the workflow with JWT auth, and SQLAlchemy stores users, tasks and daily summaries.

The key design choice: model output is treated as untrusted. The classifier asks for JSON, strips stray markdown, and falls back to a default category and priority if parsing fails, so a bad reply never breaks a check-in.

What came of it

  • A working end-to-end product: sign up, morning sync, evening review and a weekly pattern view, live on a public URL.
  • A real bug found and fixed: new tasks defaulted to a due date of "now", so every fresh task was flagged overdue. They now get an end-of-day due date.
  • Honest limits: agent state is held in memory and resets on a server restart, and the weekly review runs on demand, not on a schedule. Persistent checkpointing is next.
